# Can it be trusted yet?

"Fire and forget" is a claim, so it gets a number. Bars below are proposed and unset until the owner rules them.

| Measure | Why | Now |
|---|---|---|
| Finish rate: goals reaching accepted without human help | The whole promise | UNMEASURED |
| Escaped defects: accepted work later found broken | A finish that's wrong is worse than none | UNMEASURED |
| Judge catch rate on seeded defects | Proves Judge can see | UNMEASURED |
| Contaminated packets | Proves the contract is enforced | UNMEASURED |
| Repeat work: time on known results | The v2 failure | UNMEASURED |
| Stops that told the truth: held items that really needed a human | Knowing when to quit | UNMEASURED |

"Modest goal" must be defined by intake: a goal the agent can state a checkable proof of done for. Goals without one are
refused at the door, so the promise covers only what it can keep.
