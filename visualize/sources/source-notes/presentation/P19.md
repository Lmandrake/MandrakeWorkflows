**What it says about motion:** UI motion guidance (screen UI, not slides), but the numbers are usable defaults. Durations: short 50-200ms (small utility), medium 250-400ms, long 450-600ms (large expressive), extra-long 700-1000ms (rare, ambient, no user input). Suggested pairs: Emphasized 500ms begin-and-end on screen; Emphasized decelerate 400ms enter; Emphasized accelerate 200ms exit; Standard 300ms; Standard decelerate 250ms; Standard accelerate 200ms. Easing: transitions without easing look stiff and mechanical; enter with decelerate, exit permanently with accelerate (impression it cannot be retrieved), exit temporarily with symmetric easing. Standard cubic-bezier(0.2,0,0,1); emphasized decelerate (0.05,0.7,0.1,1); emphasized accelerate (0.3,0,0.8,0.15). Exits shorter than entrances. Pages state the easing/duration system is no longer maintained; M3 Expressive (May 2025) replaces it with a spring-based motion physics system. When to animate: transitions that traverse more screen get longer durations. **Reduced motion: not addressed** in the captured pages. **Transition types:** enter, exit permanent/temporary, begin-and-end on screen.

**Evidence / n:** One vendor design system; guidance, not measured effect. Rendered text, not citation authority; re-verify quotes against live pages.
